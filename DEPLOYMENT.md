# Deploying HybridAgent to Vercel

## Prerequisites
- **Node.js** (v18 or later) and **npm** installed locally.
- **Vercel CLI**: install globally with `npm i -g vercel`.
- A Vercel account (sign‑up at https://vercel.com) and the project linked to your Git repository (or use the CLI to create a new project).
- All required environment variables (e.g., Firebase config, API keys) added to Vercel. You can set them via the Vercel dashboard under *Settings → Environment Variables* or with the CLI `vercel env add`.

## 1. Add a `vercel.json` configuration file
Create a `vercel.json` in the project root with the following content:
```json
{
  "version": 2,
  "builds": [
    { "src": "package.json", "use": "@vercel/static-build", "config": { "distDir": "dist" } }
  ],
  "routes": [
    { "src": "\/(.*)", "dest": "/$1" }
  ]
}
```
This tells Vercel to run the build script defined in `package.json` (typically `npm run build`) and to serve the static files from the `dist` folder generated by Vite.

## 2. Ensure the build script works locally
Run the following commands in the project directory:
```bash
npm install          # installs dependencies
npm run build        # produces the `dist/` folder
```
If the build succeeds without errors, Vercel will be able to run the same command.

## 3. Add environment variables to Vercel
Identify the variables you use in the project (e.g., `VITE_FIREBASE_API_KEY`, `VITE_FIREBASE_AUTH_DOMAIN`, …). Then add them:
```bash
vercel env add VITE_FIREBASE_API_KEY production
# repeat for each variable
```
Or add them manually in the Vercel dashboard.

## 4. Deploy
From the project root, run:
```bash
vercel            # follow the prompts to link/create the project
vercel --prod    # deploy the production version
```
The CLI will output a preview URL and, after `--prod`, the production URL.

## 5. Optional: Connect to a Git repository
If you prefer Git‑based deployments, push the repository to GitHub, GitLab, or Bitbucket and import the repo in Vercel. Vercel will automatically run the build on each push to the `main` (or chosen) branch.

## 6. Verify the deployment
Open the provided URL and ensure:
- The app loads without console errors.
- Auth flows work (Firebase Auth redirects correctly).
- All API calls succeed (CORS is configured properly on the backend).

## 7. Common Issues & Fixes
| Issue | Likely Cause | Fix |
|-------|--------------|-----|
| `Cannot find module 'vite'` during build | `node_modules` missing on Vercel | Ensure `npm install` runs; Vercel does this automatically. |
| Environment variables are undefined | Not added to Vercel or missing `VITE_` prefix | Add them via `vercel env add` or the dashboard. |
| Routing 404 on refresh | Vite SPA needs fallback | The `routes` entry in `vercel.json` already provides a fallback to `index.html`. |
